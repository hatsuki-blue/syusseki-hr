# 出席QR（syusseki-hr）

朝の決まった時間帯に、出席確認用のQRコードと本日の時間割をAndroidのロック画面へ表示するアプリです。Xiaomi 14T（HyperOS）向けに作っています。

## できること

- 設定した曜日・時間帯（初期値：平日 8:00〜9:00）だけ、ロック画面にカードを表示
- カードにはQRコード、いま/つぎの授業、きょうの時間割を表示（タップでQRを拡大、上下ドラッグで位置変更）
- 表示方式は2通り
  - 浮かべるカード：本物のロック画面の上に重ねて表示（ユーザー補助サービスを使用）
  - 通知カード：ロック画面の通知として表示
- QR画像の取り込みと切り抜き、時間割の編集、テーマカラー、次回スキップ、クイック設定タイル

## 時間割データについて

このリポジトリの `assets/timetable.json` にはクラス名だけが入っていて、時間割の中身は空です。インストール後にアプリの「時間割を確認・編集」から入力してください。

自分用に同梱したい場合は、次の形式で `data` を埋めてからビルドします。

```json
{
  "version": "任意の説明",
  "classes": ["3J"],
  "data": {
    "3J": [[0, 1, 2, "国語", "担当教員", "HR教室"]]
  }
}
```

1件は `[曜日(月=0〜金=4), 開始時限, 終了時限, 科目名, 担当教員, 教室]` です。

## ビルド

Gradleを使わず、Android SDKのツールを直接呼びます。必要なもの：JDK、`aapt2`、`dalvik-exchange`（dx）、`zipalign`、`apksigner`、Android 14（API 34）の `android.jar`。

```sh
ANDROID_JAR=/path/to/platforms/android-34/android.jar ./build.sh
```

`build/AttendQR.apk` ができます。署名鍵 `keystore.jks` は初回に自動生成され、リポジトリには含めません（`.gitignore` 済み）。鍵が変わると上書きインストールできなくなるので、自分の鍵は手元で保管してください。

## 権限

通知、フォアグラウンドサービス、起動時の再開、正確なアラームだけを使います。インターネット権限はありません。ユーザー補助サービスはカードを重ねて表示するためだけに使い、画面内容の読み取りは無効にしています。

## 注意

- Playストア外のアプリなので、インストール時に Google Play プロテクトの警告が出ることがあります。
- 祝日・休校日の自動判定はありません（「次の1回をスキップ」で対応）。
